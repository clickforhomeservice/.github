## What we do

ClickForHomeService is a home-services platform that puts every common home project behind **one phone number and one call-back form**. A homeowner picks a trade, sees typical US cost ranges and a budget calculator, then either calls our team or asks for a call back at a time that suits them. One team handles the request, so it is not passed around to a list of strangers.

Every trade has its own page with an answer-first summary, a captioned cost table, what changes the price, FAQs, and an interactive **Estimated Budget Calculator**. The numbers are planning estimates, never quotes: the contractor sets the final price after assessing the job.

## How it works

1. **Call us or request a call back.** Tell us your ZIP code, the trade and a time that suits you.
2. **Talk it through with our US-based team.** We confirm the details and answer your questions.
3. **Get a quote and decide.** There is no obligation to go ahead.

## Built to be trusted

- **Consent you can prove.** Every request stores the exact consent wording, time and device details, so we can show when and how someone agreed to be contacted.
- **Do-not-call is honoured.** A one-step opt-out page, and a suppression list that blocks every future call to that number.
- **Civil calling hours.** Calls only between 8:00 AM and 9:00 PM in the homeowner's local time.
- **Honest numbers.** Typical ranges are labelled as estimates, with the factors that move the price.
- **Plain language.** No pressure, no fake discounts, and no claims we cannot back up.

## Under the hood

| Layer | Choice |
|---|---|
| App | Next.js 15 (App Router), TypeScript, Tailwind CSS |
| Rendering | Static-first pages with a small JavaScript budget |
| Data | Node.js with MariaDB/MySQL, parameterized SQL, a deliberately small connection pool |
| Security | Strict browser security headers, request-size limits, host validation, rate limiting, signed one-time conversion tokens, and a full code review of every route plus an automated security regression suite |
| Accessibility | Labelled forms, skip links, visible focus, keyboard-friendly controls, and motion that respects reduced-motion settings |
| Search | Structured data for services, FAQs and breadcrumbs; a sitemap; clean canonical URLs |
| Brand | One house-in-a-ring-of-services mark, Fraunces headlines, a forest-teal and warm-orange palette |
